# RM-CONNECTOR-001 requirements

| ID | Requirement | Verification |
|---|---|---|
| `RM-CONNECTOR-R001` | **Migrate connector imports to the public SDK boundary.** repository-manager keeps its existing Git, branch-management, and release tooling in place while migrating the imports under `agents/[p-s]*/**` that reached the shared agent-orchestration package's connector transport so they call the public agent-connector-sdk API instead, keeping direct agent-orchestration imports only at the boundary where an actual orchestration decision is made. | Import and contract tests confirm repository-manager's tool entry points execute through the public SDK API without reaching the retired private connector modules. |
| `RM-CONNECTOR-01` | **Classify every import from the orchestration package.** repository-manager inventories every production and test import drawn from the shared agent-orchestration package and classifies each one as orchestration, connector transport, governance, or obsolete. | A machine-readable import inventory assigns exactly one classification to every matching import, including dynamic imports, with none left unclassified. |
| `RM-CONNECTOR-02` | **Route connector transport imports through the public SDK.** Imports classified as connector transport are replaced with calls to the public agent-connector-sdk API, and imports of the orchestration package remain only at the boundary where repository-manager actually makes an orchestration decision. | Import and contract tests exercise repository-manager's tool entry points and confirm none reach the retired private connector modules. |
| `RM-CONNECTOR-03` | **Keep governance imports under repository-manager authority.** Development-governance imports such as queueing, reservation, and safe-commit stay under repository-manager's own existing authority rather than being routed back through the shared orchestration package. | Queue, reservation, and safe-commit tests exercise repository-manager's own implementations rather than the orchestration package's. |
| `RM-CONNECTOR-04` | **Preserve MCP/CLI contract during connector migration.** The migration preserves every public MCP and CLI action name, its typed arguments, validation rules, and error categories, or introduces an explicitly versioned, documented change rather than a silent break. | A golden tool-schema comparison plus representative success and refusal response fixtures confirm the public contract stays compatible across the migration. |
| `RM-CONNECTOR-05` | **Remove dead connector adapters after cutover.** Once the new connector path passes its tests, repository-manager removes the dead adapters, duplicate publishers, and fallback imports that supported the old path. | A source scan finds no remaining active import of the retired modules, and the package build and smoke tests pass. |
