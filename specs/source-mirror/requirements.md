# CONN-REPOSITORY-MANAGER requirements

| ID | Requirement | Acceptance |
|---|---|---|
| `CONN-REPOSITORY-MANAGER-R001` | **Full-history import into engine changesets (compose).** `repository_manager/source_mirror/importer.py` walks every commit of a git repository in topological order. It reuses the batched tree walk of SDK-REPOSITORY-TRANSPORT-R003. It submits each commit as one changeset with its parents. EG-SCM-R010 computes the object IDs. Import is idempotent: a re-run submits only unseen commits. Refusal: a commit with a missing parent or blob stops the import at that commit with a typed reason. | `tests/test_source_mirror_import.py::test_import_is_topological_idempotent_and_id_preserving` imports a 500-commit fixture twice. It asserts identical commit IDs and no second submission. |
| `CONN-REPOSITORY-MANAGER-R002` | **Mirror push after each accepted changeset (compose).** `repository_manager/source_mirror/pusher.py` pushes each accepted changeset of an `engine_primary` repository to every configured git mirror. The push is a lease-protected ref update. Each remote gets its own outcome receipt, as in RM-IDENTITY-06. The pusher must finish within 60 seconds of the accept. Refusal: a rejected or stale lease records a partial status. The pusher never reports success for a partial push. | `tests/test_source_mirror_push.py::test_push_is_leased_per_remote_and_never_reports_partial_success` drives one success, one rejected lease and one outage. |
| `CONN-REPOSITORY-MANAGER-R003` | **External commits and drift (compose).** A commit that lands on a mirror from outside the engine imports through R001 as a changeset. The engine then accepts or refuses it under EG-SCM-R003. A mirror head that differs from the engine head for more than 5 minutes is a drift finding. Refusal: a refused external commit records a typed finding and leaves both heads unchanged. | `tests/test_source_mirror_drift.py::test_external_commit_imports_and_drift_is_reported` asserts the import, the refusal finding and the drift finding. |
| `CONN-REPOSITORY-MANAGER-R004` | **Cutover, rollback and local merge-queue retirement (wire).** The connector reads the EG-SCM-R012 authority record before each write. For an `engine_primary` repository, `repository_manager/merge_queue.py` and `repository_manager/landing_policy.py` refuse to land. For `mirror_primary`, both keep working as now. The rollback command sets `mirror_primary` and stops the pusher. Refusal: a write to the non-authoritative side refuses with a typed reason. | `tests/test_source_mirror_queue_retire.py::test_queue_refuses_engine_primary_and_rollback_restores_it` switches authority both ways and asserts each refusal. |
