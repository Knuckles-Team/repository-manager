| ID | Requirement | Acceptance |
|---|---|---|
| `CONN-REPOSITORY-MANAGER-CONNECTOR-CONTENT-R001` | **Default content.** `pyproject.toml` declares `repository-manager-mcp` as the single `agent_connector_sdk.connector` entry point. The server lists the packaged `skill://` and `ontology://` resources and the packaged prompts with no `content=` argument. Proving test: `tests/test_default_content_surfaces.py`. | `resources/list` includes `skill://` and `ontology://`; `prompts/list` includes each packaged prompt. |
| `CONN-REPOSITORY-MANAGER-CONNECTOR-CONTENT-R002` | **Serve the repository index tool with incremental state.** Subsystem: connector. Caller: `repository_manager/mcp_server.py` → `register_tool_surface` → tool `index_repository`. The tool accepts the previous `RepositoryIndexState` and returns index pages for changed files only, in `syntax` or `typed` mode. The connector owns git access; the SDK owns state, paging and receipts. Refusals: `unsupported_language`, `invalid_type_mode`. Writes: none. Depends on: SCION-SOURCE-INGEST-R004.15. | Test: `tests/test_index_repository_served.py::test_tool_returns_changed_files_only` (L3) edits two files of a fixture repository and asserts the page. |
| `CONN-REPOSITORY-MANAGER-CONNECTOR-CONTENT-R003` | **Serve repository hydration through the SDK transport.** Subsystem: connector served tools. Caller: arbora MCP → `repository_manager/mcp_server.py` → `register_tool_surface` → tool `rm_repository_hydrate`. Arguments: `repository_id` and `ref`. The tool builds `LocalGitRepositoryProvider` for the registered workspace and resolves the immutable revision. It calls `scion_sdk.repository.index_repository_snapshot` with the engine client of the caller. It returns the `RepositoryIndexReceipt` fields: revision, batch count and manifest digest. The tool carries no read-only hint because it writes to the engine. Refusals: `REPOSITORY_UNKNOWN` for an unregistered repository and `REF_UNRESOLVED` for a ref that does not resolve. Writes: engine records through the SDK only. Depends on: SCION-REPOSITORY-TRANSPORT-R001, SCION-REPOSITORY-TRANSPORT-R002, CONN-REPOSITORY-MANAGER-CONNECTOR-CONTENT-R002. | Test: `tests/source_changesets/test_hydrate_served.py::test_hydrate_indexes_a_fixture_repository_through_arbora` (L3). It indexes a fixture repository through arbora MCP and reads the manifest back from the engine. |
| `CONN-REPOSITORY-MANAGER-CONNECTOR-CONTENT-R004` | **Code reads come from the graph.** The file, tree, blame and search tools read through medulla `ReadTree` and the code graph (`EG-SDLC-R012`, `EG-SCM-R004`) for any repository that medulla holds. A local clone is used only for a repository that medulla does not hold yet. The ingest tool submits each listed repository through `SourceIngest` (`EG-SDLC-R012.1`). | Test: `tests/test_graph_reads.py::test_tree_and_blame_read_from_the_engine` runs against a recorded engine. |
